# 製品要件

目的は非負整数の素数判定と素因数分解です。素数列挙は初期目的に含めません。
旧 WordPress / Flask への依存を引き継がず、静的 asset 取得後はブラウザ内で計算します。

中核の性能目標は、大きな半素数をなるべく高速に、なるべく多い桁まで分解することです。
backendとの計算通信は行いません。BigIntのみを最終engineに固定せず、WASM・多倍長library・方式を評価します。
因子バランス・入力規模・端末・時間予算ごとの完了率と限界を示し、無制限の桁数や時間を保証しません。
[性能計画](../architecture/performance-plan.md) と [サイト受入れ案](../contracts/site-adapter.md) を参照してください。

- 大きな整数を丸めず、科学的記法も結果が整数になる場合だけ受け入れます。
- 入力の科学的記法と、因数の累乗表示は別の機能です。
- 0 と 1 は「素数でも合成数でもない」と表示します。
- 証明済み素数、確率的素数、合成数、未完了、取消を区別します。
- 因子と未解決残余の積が元の入力に一致することを検証します。
- 入力可能な桁数は、分解完了を保証する桁数ではありません。
- 長時間計算には専用 Worker、取消、時間・操作予算、同時実行制御を備えます。
- 結果は提出時入力と job ID に結びつけ、古い応答を表示しません。
- 数式表示にはネイティブ要素を使い、MathJax や外部 CDN は不要です。
- 初期配布に iframe、PWA、自動更新、外部スクリプト、保存、解析送信を含めません。

この初回 PR は入力と表示用データのコアまでです。
暗号鍵生成や定時間実行の保証は対象外です。公開、デプロイ、既存サイト組込は別途判断します。
