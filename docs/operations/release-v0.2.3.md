# 0.2.3 結果表示修正版の配布

PR40 のマージ d35cb34adcdbae0013a207f7514357209715b75c を基点とする。正常終了した complete と probable は紫の満杯を保持し、時間切れ・エラー・取消・未完了、新入力・再実行を区別する。ゲージは処理の進捗を表し、素数の証明確度を表さない。

因子は「素数（確定）」「素数と判定（未証明）」「不明」を区別する。全体の probable は「分解結果（未証明の因子あり）。」とし、合成数の入力全体を素数と呼ばない。固定7基数の Miller–Rabin が確定を保証するのは 2^64 未満で、それ以上に独立乱数の誤受理率や事後確率を付けない。算法・入力・資源・Worker・CSP・依存の契約は変更しない。

版情報を揃えた最終対象で全体試験と check、別々の clean checkout による配布物2件の全ファイル一致、配布物のブラウザ受入、対応ソース ZIP と追跡 blob の照合を行う。main と tag の CI は exact commit・event・attempt を記録する。過去の Chrome 起動タイムアウトと同一 SHA 再実行の成功を混同しない。

runtime ZIP、同じタグ対象の完全な対応ソース ZIP、SHA256SUMS.txt、RELEASE-PROVENANCE.json、公開可能なブラウザ受入記録を新しい v0.2.3 へ配布し、匿名取得でハッシュを再照合する。既存タグと資産は上書きしない。実機スマートフォン、Safari/Firefox、スクリーンリーダー操作の未検証範囲を明記する。サイトへの採用と本番配信はリリース公開と別工程であり、npm 公開は行わない。

配布物の任意実ブラウザ受入スクリプトも現行表示へ同期する。旧「確定判定」と probable 終了後の空ゲージ、取消コピーの旧長文を期待する検査を修正し、通常完了の満杯・新入力の解除・未証明の accessible name を確認する。計算実装の変更ではない。
