# 限定プレビューの操作部品調整

基準は toolkit c221b0d8fb66cb585f3a800e57105a9d700451e3 / Site 285a1190d92a5da23c49aee846c704b1c87c758e。限定HTTPプレビューの入力・例・設定・結果を新規撮影し、desktop WebKitで画素を確認した。実iOSの受入ではない。

結果の直前で一段を占めていた「結果へ戻る」を削除する。専用処理・見出しtabindex・テスト操作を整理し、開始・取消・コピー・モーダルの必要なfocus処理と状態通知は保つ。入力例は入力のみ、設定は適用／取消、表示は一つの結果のままとする。

Siteの既存色・2px角丸・端末フォントを維持する。分解と設定適用を主操作として塗り、閉じる／消去は控えめにする。見出しと設定フッターに細い区切り線を置き、取消→適用の順にする。モーダル全体のスクロールと44px／rem以上の操作領域を維持し、新しい装飾・導線・固定フッター・CSP変更は加えない。

変更前に撤去の検査が失敗することを確認し、変更後の関連49テストとcanonical artifact検査は成功した。最終headの全体検査・独立レビュー・固定成果物でのFirefox／WebKit検証と配信後のhash照合を、限定プレビュー切替の条件とする。具体的結果は当該タスクのhash付き報告に記録する。

Site合成検査は全入力例、主副ボタン、閉じる・取消・適用・コピー・実行中止について通常／focus／hover／active／disabledを計測する。狭幅と短いviewport、文字200%、keyboard・Escape・元のscrollへの復帰、実行／取消／再実行とHTTP手動コピーを確認する。独立したモバイル・desktop画面も撮影する。

実iOS／Androidのソフトキーボード・IME・OS clipboard、VoiceOver等の支援技術、BFCache、正式React採用は対象外。HTTP上のsecure context保証や外部iPhone到達をローカル確認から推定しない。公開・push・merge・正式リリース・本番配信は保留する。v0.1.2のtag CI初回Native validation失敗と再実行成功の原因未確定という履歴も維持する。
