# モバイルで入力から結果までの距離を短くする変更

2026-10-24 の確認用ページへの指摘を受けた表示上の変更。基準は toolkit `037468b7aabe2f88789c9ce933ef91811506ac3c` と Site/header `c7aa2985359fdfb6208d78b1ad930f4c240402f3`。数値処理・Worker protocol・通常の入力境界・実行予算の方針は変更しない。

## 操作

- 入力の直下に分解・取消・リセットを置く。進行状況と結果が続き、入力例・設定の開閉が結果との間に入らない。
- 折り畳みを開かずに「360 を入力して分解（1秒上限）」を押せる。固定した小入力のみを1000ms上限で開始し、次回の設定値を保つ。大きな入力例の汎用ボタンは引き続き入力だけを変える。
- 結果があるときの「結果へ移動」は、利用者の操作で全桁欄へ focus と表示位置を合わせる。完了時の自動スクロールは加えない。取消から状態への既存の focus 引継ぎ以外に、別の control の focus を奪わない。
- 実経過とその測定範囲、設定上限、因子ごとのリスト、未分解部分と停止理由、コピー用の全情報は保持する。

## 検証記録

最初の挙動テストは3件失敗し、実装後は対象12件すべて成功した。独立した任意の Playwright Core 1.61.0 runner で desktop Firefox 151.0 / WebKit 26.5 各15項目が成功。明示的な360実行と次回設定保持、結果への keyboard 移動、入力例が自動実行しないこと、取消と再実行、copy の成功・拒否・未対応、10因子、Worker と Blob URL 解放、280/320/393px と文字100/200%を含む。raw report と screenshot は作業用領域に保存し、リポジトリへ利用者の画像を含めない。

最初の `scroll-margin` の `calc(... + ...)` は Site の canonical CSS 検査に拒否された。検査を変えず、その指定を除き全桁欄への明示的な中央移動を使う形に直し、artifact-only 検査に成功した。この履歴を実行障害や数値不具合とは扱わない。

最終headの全テスト・静的検査、固定成果物の作成・比較、Site と組み合わせた確認ページの検証結果は別途実行記録に保存する。確認用ページはビルド済み Site へ toolkit を直接マウントするもので、最終 React 統合・正式 v0.1.3・本番配信ではない。HTTP で安全な接続を必要とする機能の制約を明記する。

実 iOS/Android の keyboard・autozoom、実機からの到達性、読み上げソフト、BFCache、OS clipboard paste は、この desktop engine 検証の保証に含めない。既存の公開保留と release ブランチへのマージ制約は維持する。v0.1.2 のタグ CI は初回 Native validation 失敗・同一source再実行成功・原因未確定という履歴を保持する。
