# 段階別の受入条件

## 初回: 入力と累乗集約
- 科学的記法の厳密な整数化、安全整数を超える値、ゼロ、境界、拒否入力を検証する。
- 入力・指数・展開桁上限を展開前に検査する。
- 因数の昇順、重複集約、指数表示、入力不変性、型と上限を検証する。
- 文書リンク、encoding、構文、最終head CI、独立レビューを完了する。
- 計算器やブラウザUIの完成と表示しない。

## 後続: 計算とWorker
- 半素数の因子バランス・入力規模・端末・時間予算ごとのbenchmarkと限界を公開可能な固定corpusで示す。
- BigInt/WASM・多倍長library・方式を比較し、成功例だけでなく打切り率とmemoryも記録する。
- [既存サイト形式の追加受入れ](../contracts/site-adapter.md)を満たす。
- 素数判定の証明範囲と確率条件を根拠資料で固定する。
- 素因数・残余の再構成、未完了、cancel、timeout、stale応答、再起動を検証する。
- 代表ケースの実測でnative / WASMとライブラリ要否を決める。

## 後続: 画面と配布
- ブラウザで準備完了後の通信ゼロとoffline時の同一結果を検証する。
- 入力と結果の対応、アクセシビリティ、ネイティブ累乗表示、ブラウザ互換性を確認する。
- license、依存pin、配布asset、source hashを確認する。
- サイトcapability変更と統合、公開・deployは別の承認を得る。
