# 通常adapter／GUIの309桁受付と有限Brent採用

2026-10-28のローカル候補です。公開済みv0.1.5、GitHub Release、Siteは更新していません。

| 選択モードと入力 | 受付と実行 |
| --- | --- |
| 通常 | 最大309桁かつ1024bit以下を受付 |
| 通常の2^128未満 | 従来staged経路。0/1、軽い入力の扱いと最大60秒を維持 |
| 通常の2^128以上 | native-only Brent。最大1 Worker、WASMなし、最大5秒・5万操作 |
| 高精度／大メモリ | 最大100桁かつ332bit。従来のSIQS・有限予算を維持 |

受付は分解完了の保証ではありません。309桁の難しい半素数を完走できるという主張ではなく、小因子・平滑数・素数候補などと、未解決の大きな残余を分けます。
Native ABIの400bitという宣言だけでは、JS／embedded Worker／資源guard／packet／結果検算が400bitへ対応した証拠にならないため、SIQSは332bitを維持します。

## 接続条件と満たした範囲

- parserの4096文字、先頭ゼロ、指数表記、309桁と1024bitの二重境界を維持し、範囲外はWorker作成前に拒否します。
- SITE_CAPABILITIESは受付上限を示し、smallInputRouteの128bitは独立に維持します。既存のmanifest項目形式は変えません。
- 入力横には受付上限と完走保証ではない旨を表示し、詳細では高精度/SIQSとの違いを説明します。
- 選択したWASM予算・時間と、今回実行したWorker/WASM/時間/計算量の上限を分けます。通常の大きい入力で設定60秒を選んでも、実際は最大5秒であることを示します。
- Document leaseを外側sessionが所有し、runnerはtokenの所有を照合して借ります。検算・退役・表示まで外側の所有を解除しません。
- controllerは因子積・確度・prefixを検証し、不変の結果を内部WeakSetへ登録します。表示は同じ入力の登録済み結果だけを受け付け、複製や改変を認めません。
- 取消、時間/計算量、検算予算、計算/通信異常、資源解放不明を区別します。停止後も検算済みの因子・余因子・probableを保持します。
- 資源解放不明では新規計算・設定・resetを禁止し、今回の検算済み結果・コピー・実測欄を表示したままにします。
