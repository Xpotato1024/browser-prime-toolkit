# 結果・補足説明の表示契約

- コピー操作は分解式の枠内に一つだけ置く。表示は重なった紙の記号とし、名前・title は「結果をコピー」。44px以上の操作領域とキーボードのフォーカス表示を維持する。
- 成否は role=status で通知する。失敗時の本文選択、未証明・未完了を含む全桁コピー、古い非同期応答の無効化を維持する。
- 因子ごとの判定と計算の詳細は「結果の詳細」にまとめる。一般説明は別の「使い方・ヘルプ」に置き、計算の範囲と未完了・未証明の説明を独立して開ける。
- 320px、390px、desktop、200%相当の再配置で式とコピー操作が重ならず、横スクロールを生まない。長い結果も省略しない。
- 数値計算、入力境界、Worker、資源上限、結果の確度は変更しない。前回の結果・取消・コピー失敗の既存操作を回帰検証する。
- 配布候補は固定source commitからbuild-site-releaseで生成し、既存ライセンス・provenanceを保つ。サイト採用、マージ、タグとRelease公開は別判断とする。
