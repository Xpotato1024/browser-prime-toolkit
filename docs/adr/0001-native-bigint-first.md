# ADR 0001: native BigInt から開始する
日付: 2026-10-18 / 状態: 初回コアに採用

旧実装は GMP/WASM を使いますが、受領物だけでは再現可能な取得・build情報が不足しています。
入力と因数集約には native BigInt で十分なため、第三者依存を持ち込まず新規実装します。
科学的記法は文字列上で厳密に展開し、浮動小数点経由の丸めを避けます。
因数累乗は構造化データで表し、外部数式レンダラーを必要としません。

本ADRは入力と因数集約だけの選択であり、最終計算engineをBigIntに固定しません。
大きな半素数の高速分解に向けて、WASM・多倍長library・方式を[性能測定](../architecture/performance-plan.md)で評価します。
初回の入力上限は性能保証ではありません。素数判定・分解・UIは後続PRです。
公開ライセンスは未選定であり、旧コードや依存の再ライセンスは行いません。
